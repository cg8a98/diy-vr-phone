# DIY Smartphone VR Headset

A 3D-printed VR headset that turns a Samsung Galaxy S23 Ultra into a headset for PC VR streaming, 2D game streaming, 3D movies and mixed reality with hand tracking and room meshing. Inspired by brenpoly's "I Built a $5 Apple Vision Pro", with better optics, comfort, cooling and eye tracking planned.
